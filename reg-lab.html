6. 결정계수(R²)

교과서 98쪽

결정계수는 모델이 데이터를 얼마나 잘 설명하는지를 나타내는 값이다. 값의 범위는 0~1 사이로, 결정계수(R²)가 1에 가까우면 선형 회귀 모델이 데이터를 매우 잘 설명함을 의미한다.

R²해석
R² = 0모델이 예측력이 없다.
0.0 < R² < 0.3약한 설명력
0.3 ≤ R² < 0.5중간 정도 설명력
0.5 ≤ R² < 0.7높은 설명력
0.7 ≤ R² ≤ 1매우 강한 설명력
