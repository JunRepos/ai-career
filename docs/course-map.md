## 6. 5차시 — 지능적 탐색 (만드는 중)

**ai-2B 08-28 · ai-2D 08-31**

### 수업 흐름 (2026-08-27 확정)

1. **인터렉티브 활동으로 DFS·BFS 마무리** — 앞 차시 내용을 활동으로 닫습니다
2. **언덕 등반** 개념 + 단계별 시연
3. **최상 우선 탐색** 개념 + 단계별 시연
4. **A\* 예고** (다음 차시)

> BFS·DFS 를 슬라이드로 다시 훑지 않습니다. 활동으로 마무리하고 넘어갑니다.

### 개념 전개 (선생님 안)

```
지능적 탐색
  → 정보를 이용한다
  → 규칙이 아니라 목적지까지의 추정치를 이용
  → 값이 클수록 좋을 때는 높은 쪽으로 (거리가 기준이면 반대)
  → 언덕 등반 탐색 알고리즘
  → 한계 : 지금보다 나은 것이 안 보이면 거기서 멈춘다
  → 이를 보완해 최상 우선 탐색이 나옴
  → 후보를 어딘가에 모아 둔다 (열린 목록 · 닫힌 목록)
     ※ 파이썬을 안 배운 학생이 있으므로 '리스트' 대신 '어딘가에 모아 둔다' 로 설명
  → 최상 우선 탐색 시연
  → 한계 : 추정치 하나만 본다 (A* 의 발판)
  → 그래서 초기 상태에서 현재까지의 정보도 함께 쓰는 알고리즘 → A*, 다음 시간
```

### 정해진 것

- **언덕 등반 예시 = 산 오르기** (고도가 높은 쪽으로. 이름과 직결되고 봉우리에 갇히는 한계가 그림으로 보임)
- **인터렉티브 활동 = B안 「숨바꼭질 — 방 찾기」** 로 먼저 만들어 보고 결과물을 보고 결정
  - 집 평면도가 트리로 이어져 있고 친구가 한 방에 숨어 있음
  - `너비 우선으로 열어보세요` 를 주고, 순서를 어기면 알려 줌
  - 몇 번 만에 찾았는지 + 어긴 횟수를 기록
  - 게임 목록은 `js/games/games.js` 의 `GAMES` 한 곳에서 관리 (HANDOFF 참고)

### 아직 안 정한 것

- 산 오르기의 구체적 판 (노드 수·고도 값·봉우리 위치)
- 최상 우선 시연에 쓸 예 (산 오르기를 이어서 쓸지, 길찾기로 바꿀지)
- 활동 시간 배분
